# Hydros

使用 Kotlin 开发的趣智校园第三方客户端

</div>

> [!WARNING]
> Hydros 仅用于「移动开发技术及应用」课程的学习实践，请于下载后24小时内删除。
> 
> 项目内所有 API 均从互联网公开信息收集，并未对原应用进行任何破解、逆向等操作，本仓库也不提供任何相关内容与教程。

## 基础功能

Hydros 的核心功能仅为连接、使用设备与查看账单情况。

> [!NOTE]
> 受微信支付 SDK 限制，第三方客户端无法实现充值功能。

## 数据收集

GitHub Releases 中的 Android APK 会通过 Firebase Analytics 收集去标识化的使用情况以协助 Hydros 修复错误或改进使用体验。此选项可随时在应用内关闭。

详见应用内「关于 → 隐私政策」。
